# Contributing to the Hasanat Ecosystem

## Ways to Contribute

### 🏗️ Build a New App

1. Use this template (click "Use this template" on GitHub)
2. Build your app locally (`npm install` → `npm run dev`)
3. Submit at [hasanat.dev/apps/submit](https://hasanat.dev/apps/submit)
4. Get your hasanat.dev subdomain

### 💡 Submit an Idea

Don't code? No problem.

1. Go to [hasanat.dev/ideas/submit](https://hasanat.dev/ideas/submit)
2. Describe the problem you want solved
3. AI will help refine your idea
4. Builders will pick it up

### 🎨 Improve Existing Apps

1. Find apps on [hasanat.dev/apps](https://hasanat.dev/apps)
2. Check their GitHub repos
3. Submit PRs with improvements

### 📝 Improve This Starter

PRs for template improvements are always welcome.

## Guidelines

### Code Standards

- TypeScript strict mode
- Biome for formatting and linting
- Bilingual: Arabic + English for all user-facing text
- Accessible: keyboard navigation, screen reader support

### Islamic Content Guidelines

- Verify Quran verses and hadith references with scholars
- Use established translations (Sahih International, etc.)
- Be respectful of different madhabs and opinions
- When in doubt, consult before publishing

## Code of Conduct

We follow Islamic principles of respect, honesty, and brotherhood/sisterhood.

- Be kind and constructive in feedback
- Assume good intentions
- Protect user privacy
- Build for benefit, not harm
